# Credits and provenance

## Design, code and writing

**Kimi**, for the **Kimi Games** workshop — game design, deterministic rules, seven puzzle maps, reference solutions, interface, EN/FR/ES writing, local save, automated tests and browser checks.

## Original visual assets

All visual assets were created for The Conservatory of Seasons:

- isometric gardens, greenhouse, suspended islands, water, ice, lianas, plants, flowers, trees, doors, lanterns and light seeds drawn with Canvas 2D;
- mechanical gardener, fruit, planters and hub restoration drawn with Canvas 2D;
- interface icons drawn with inline SVG paths;
- `art/cover.png`, generated by the original `art/render_cover.py` drawing program.

No stock image, external sprite, external font or third-party art asset is used. The interface uses local system font families (Georgia, Segoe UI and Trebuchet MS fallbacks), not redistributed font files.

## Original audio

All sound effects are synthesized live with the Web Audio API. No recordings, samples or music files are included. Audio is optional and can be muted.

## Tools

Python's standard library builds the self-contained HTML export. Node's built-in test runner executes the rules and solution checks. Pillow is used only by the optional cover generator and is not included in the game or required to play.

No third-party runtime libraries, remote services, external assets or inherited asset licences are present. Code and original media are released under the MIT License in `LICENSE`.
